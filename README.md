# 🧠 Health-Fitness Virtual Agent

An intelligent AI-based virtual assistant that provides personalized health and fitness recommendations based on user inputs such as age, weight, height, and fitness goals.

---

## 🚀 Key Features

- 📊 Calculates Body Mass Index (BMI)
- 🏋️ Generates personalized workout plans
- 🥗 Provides diet recommendations based on user goals
- 🔄 Dynamic response system based on user inputs
- 💡 Modular and scalable design for easy enhancements

---

## 🛠️ Tech Stack

- **Backend:** Python (Flask)
- **Libraries:** Pandas, NumPy
- **Frontend:** HTML, CSS, JavaScript
- **Concepts Used:** Input Validation, API Integration, Modular Programming

## ▶️ How to Run the Project

1. Clone the repository:
   git clone https://github.com/your-username/health-fitness-agent.git

2. Navigate to the project folder:
   cd health-fitness-agent

3. Install dependencies:
   pip install -r requirements.txt

4. Run the application:
   python app.py

5. Open browser and visit:
   http://127.0.0.1:5000/
